# MISHA — Experience Platform

`misha.systems` is the demonstration and presentation environment for MISHA Systems.

## Purpose

This site is intentionally separate from `mishasystems.com`:

- `mishasystems.com` — corporate website
- `misha.systems` — interactive product demonstrations and presentations

## Initial experiences

- eTA & Biometric Fastlane
- ED Card Portal
- Platform architecture / traveller journey

All content is in English and the UI is responsive for desktop, tablet and mobile presentation use.
